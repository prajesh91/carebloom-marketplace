# 09 - Provider Onboarding Guide (Ontario MVP)

## 1. Onboarding Journey & Funnel
A caregiver's onboarding lifecycle follows a 16-step validation pipeline:

```
[Account Creation] → [Identity Check] → [Email & Phone Verifications]
                               ↓
[Gov ID Upload] ← [Selfie Biometrics]
       ↓
[License Check] → [Insurance Verification] → [Police VSS Background Check]
                               ↓
[Reference Audit] ← [Interview Screening]
       ↓
[Compliance Training] → [Policy Acceptance] → [Marketplace Agreement]
                               ↓
[Admin Review] → [Status Approved] → [Dashboard Activated]
```

## 2. Transition Gateways
* **Draft State:** Profile created but lacking documentation.
* **Pending Verification:** Documents submitted; awaiting manual admin review.
* **Active Match State:** Approved by admin. Profile eligible for search queries.
* **Suspended/Expired State:** Automatically triggered if a mandatory document expires.
