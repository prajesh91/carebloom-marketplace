# 06 - Admin Handbook (Ontario MVP)

## 1. Compliance Verification Framework
Admin coordinators act as gatekeepers for CareBloom. Every profile must be manually audited before listing on the marketplace.

## 2. License Auditing (CNO, CPO, COTO)
1. **Verification portal:** Query the official college registry search.
2. **Details match:** Confirm spelling of the legal name and check for restrictions, conditions, or open disciplinary findings.
3. **Registry record:** Save registry snapshot to secure compliance vault.

## 3. Vulnerable Sector Check (VSS) Review
Admins must verify that uploaded VSS documents:
- Show clear watermarks from official police services (e.g., OPP, TPS, PRP).
- List the provider's correct legal name.
- Contain no criminal convictions or findings relevant to vulnerable client groups.

## 4. Handling Incident Escalations
When a caregiver flags a clinical symptom or a family logs a complaint:
1. **Clinical Escalations Feed:** Check the active alerts immediately.
2. **Interim Measures:** Suspend matching if physical safety is threatened.
3. **Resolution:** Contact the caregiver and family, record coordinator notes, and mark as resolved once verified.
